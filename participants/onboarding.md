# Onboarding

Checklist for bringing a newly accepted participant (`applicant/accepted`)
into an active cohort (`applicant/active`).

## Checklist

- [ ] Create profile under `participants/profiles/` per that folder's
  README template.
- [ ] Confirm support package with participant (funding, mentorship,
  space, network) per `participants/support-offered.md`.
- [ ] Assign mentor(s), update `participants/mentors.md`.
- [ ] Share access to [space / tools / communication channels — TBD].
- [ ] Confirm expectations and any commitments in writing (e.g. a simple
  participation agreement — [TBD if/what this looks like legally]).
- [ ] Add to relevant recurring commitments in `operations/calendar.md`
  (e.g. cohort check-ins, demo day).
- [ ] Update issue label to `applicant/active`.

## Reminder

Do not collect or store financial need, immigration status, or other
sensitive PII during onboarding paperwork stored in this repo — see
`governance/data-protection.md`. If onboarding requires this information
(e.g. for a stipend), it should be collected and stored in the
[system TBD] the founding team designates, not here.
