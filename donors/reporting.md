# Donor reporting

Cadence and content for keeping donors informed.

## Cadence

| Report | Frequency | Owner | Audience |
|---|---|---|---|
| Quarterly update | Every quarter | [board member — TBD] | All active donors |
| Annual report | Once per fiscal year, after GA approval of accounts | [board — TBD] | All donors + public (if published) |

This should also appear in `operations/calendar.md` alongside other
recurring commitments — keep both in sync. A scheduled reminder for the
quarterly update also exists as
`.github/workflows/donor-report-reminder.yml`, which opens a GitHub Issue
each quarter so the task doesn't get lost.

## Quarterly update — content

- Cohort/participant progress (de-identified/aggregate — see
  `participants/model.md`)
- Notable milestones (events, new partnerships)
- Financial snapshot at a level appropriate for external readers (no
  per-donor amounts)

## Annual report — content

See `donors/comms/annual-report-outline.md` for the section-by-section
outline. The annual report should be approved by the board before
distribution and should align with the GA-approved annual accounts.
