# Planning

Working notes and roadmaps — cohort plans, upcoming milestones, ideas not
yet ready to be policy. Less formal than `governance/` or `strategy/`;
things here can move fast and go stale, unlike statutes or the narrative.

## Suggested structure

As planning docs accumulate, consider one file per planning horizon or
cohort, e.g.:

- `planning/cohort-<id>.md` — plan for a specific upcoming cohort
  (track mix, timeline, target participant count — see
  `participants/model.md`)
- `planning/roadmap.md` — longer-horizon organizational roadmap

No planning documents exist yet — add them as real plans take shape
rather than pre-creating empty placeholders.
