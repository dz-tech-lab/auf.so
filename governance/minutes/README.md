# Minutes

Board meeting and General Assembly minutes, filed one per meeting.

## Filing convention

- File name: `YYYY-MM-DD-<board|ga>-minutes.md` (e.g.
  `2026-03-15-board-minutes.md`).
- Each file should record: date, attendees, apologies, agenda, decisions
  (with reference to any board resolution filed under
  `governance/templates/board-resolution-template.md`), and action items.
- Minutes are a **point-in-time record** — once filed via PR and merged,
  treat them as historical fact. Corrections go in a follow-up minute
  ("correction to minutes of [date]"), not an edit to the original file.

## What not to put in minutes

Do not record real PII (see `governance/data-protection.md`) — e.g. a
participant's financial need or a donor's payment details — even in
passing discussion notes. Reference the relevant Issue or record instead
(e.g. "discussed donor pipeline, see #42").
