# Entity registry

Authoritative reference for the Association's legal identifiers and
signing authority. This is a **structural/legal facts** file, not a
financial one.

**Do not add bank account numbers, IBANs, or any payment details here or
anywhere else in this repo** — see `governance/data-protection.md`. If a
process needs to reference "the bank account," refer to it by name only
(e.g. "the operating account at [bank name]") and keep the actual number
in whatever off-repo system the founding team designates.
